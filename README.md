# Rafiq AI

منصة تعليمية عربية لبناء بيئة تعلم منظمة مع أدوات ذكاء اصطناعي. المشروع قيد التنفيذ على مراحل؛ راجع [خطة العمل](#حالة-التنفيذ) أدناه.

## المتطلبات
- Node.js 20 أو أحدث وnpm 10+
- PostgreSQL 16 أو أحدث

## التشغيل المحلي
1. انسخ `.env.example` إلى `.env` وأدخل بيانات PostgreSQL وسر JWT قوية.
2. أنشئ قاعدة البيانات وشغّل المخطط: `psql "$DATABASE_URL" -f apps/api/src/db/schema.sql`
3. ثبّت الحزم: `npm install`
4. شغّل الواجهة وواجهة API: `npm run dev`
5. افتح العنوان الذي يعرضه Vite (عادة `http://localhost:5173`). واجهة API تعمل على المنفذ 4000.

## أوامر مفيدة
- `npm run dev` تشغيل الواجهة وAPI بالتوازي.
- `npm run build` بناء الواجهة للإنتاج.
- `npm start` تشغيل API.

## متغيرات البيئة
`DATABASE_URL`, `JWT_SECRET`, `PORT`, `CLIENT_ORIGIN`. لا تضع المفاتيح السرية في الواجهة أو في Git.
